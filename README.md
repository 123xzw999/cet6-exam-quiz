## 功能

- **考试模式**：一次看完整套题，像真卷一样连续排布；提交后出成绩报告
  （答对 / 答错 / 未答 / 正确率 / 客观题折算分 / 分题型统计），每题标记对错并展开解析
- **听力原声**：接入真题 HLS 音频流，附 7 个分段的跳转按钮（Section A/B/C 各篇）
- **主观题**：写作提供参考范文 + 整篇中译 + 逐段拆解；翻译提供参考译文 + 逐句解析
  （主干 / 降级 / 语法 / 译文）；作答内容自动保存草稿
- **答题卡**：按题型分组，答对绿 / 答错红 / 未答灰，点击跳题
- **即时判分**：点选项立刻判对错，正确项标绿、错误项标红
- **进度统计**：年份 / 套卷两级进度条、累计正确率
- **快捷键**：`A–D` / `E–O` 选答案、`←` `→` 切题、`D` 开关透明模块

## 特色功能：透明模块

右下角「透明模块」按钮，点一下：

1. 整个页面被一层**完全透明的玻璃层**笼罩 —— 不模糊、不变暗、**不改变网站可视度**
2. 这一层上可以**直接手写**（鼠标 / 触屏 / 手写笔），用来圈重点、划句子、记笔记
3. **按钮和工具栏所在区域不会被笼罩** —— 画布用 `clip-path` 在那里挖了洞，
   指针落进该区域也不会落笔
4. **再按一下按钮**，透明模块消失，笔迹保留

工具栏：5 种颜色（含黄色荧光笔）、3 档粗细、橡皮、撤销、清空、存图 PNG、**穿透**
（开启后点击可穿过涂层去操作页面）。笔迹按题保存。

## 技术说明

纯静态站点，无后端、无构建步骤：

```
index.html         页面骨架（含登录页）
css/style.css      主题：外围粉色渐变 + 题目区纯白
css/ink.css        透明模块
js/store.js        本地记录（答题 / 错题 / 收藏 / 草稿）
js/app.js          路由与全部视图（登录/首页/考试/主观题/刷题）
js/ink.js          透明模块 + 手写引擎
data/index.js      46 套卷索引（含考期归属、题号、题型分布）
data/audio.js      27 套听力音频地址 + 分段时间轴
data/papers/*.js   每套题的完整数据（按需加载）
```

- 题库数据通过动态注入 `<script>` 加载而非 `fetch`，所以 `file://` 双击也能打开
- 听力音频是 HLS（.m3u8）流，用 hls.js 播放；Safari 走原生支持；
  若播放器不可用，卡片里保留了来源页链接作为兜底
