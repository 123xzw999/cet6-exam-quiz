# 六级真题刷题 · CET-6 2020–2026

把《英语六级 CET6 2020-2026 真题题目册》和配套的《答案解析与词汇册》两本 PDF
转成了一个科目一式的在线刷题网站。

**1859 道真题，每题都有标准答案和逐题解析。**

## 题库

| 题型 | 题号 | 题量 | 说明 |
|---|---|---|---|
| 听力理解 | 1–25 | 675 | 题干取自解析册，附在线录音页链接 |
| 选词填空 | 26–35 | 390 | 15 选 10，原文空位已回填标注 |
| 长篇阅读（信息匹配） | 36–45 | 394 | 13 段选 10 句，附原文段落 |
| 仔细阅读 | 46–55 | 400 | 四选一，附阅读原文 |
| **合计** | | **1859** | 覆盖 46 套真题（2020.07 – 2026.06） |

每题包含：英文题干、中文翻译、选项、**标准答案**，以及解析册里的
`定位 / 信号 / 替换 / 排除`（阅读为 `判型 / 拆句 / 定位 / 选项`，
匹配为 `锚点 / 改写 / 辨邻`，完形为 `词性槽 / 依据 / 竞争词 / 易错`）。

## 功能

- **六种练习模式**：顺序刷题 / 随机 100 题 / 按套卷模考 / 按题型专项 / 错题本 / 收藏
- **即时判分**：点选项立刻判对错，正确项标绿、错误项标红
- **逐题解析**：按解析册的分类分区展示，同义替换处自动高亮
- **答题卡**：按题型分组，答对绿 / 答错红 / 未答灰，点击跳题
- **阅读原文**：宽屏左原文右题目双栏，窄屏可折叠
- **进度统计**：每套卷进度条、累计正确率、套卷成绩估算
- **快捷键**：`A–D` / `E–O` 选答案、`←` `→` 切题、`空格` 看解析、`D` 开关透明模块

## 特色功能：透明模块

右下角「透明模块」按钮，点一下：

1. 整个页面被一层**完全透明的玻璃层**笼罩 —— 不模糊、不变暗、**不改变网站可视度**
2. 这一层上可以**直接手写**（鼠标 / 触屏 / 手写笔），用来圈重点、划句子、记笔记
3. **按钮和工具栏所在区域不会被笼罩** —— 画布用 `clip-path` 在那里挖了洞，
   指针落进该区域也不会落笔
4. **再按一下按钮**，透明模块消失，笔迹保留

工具栏：5 种颜色（含黄色荧光笔）、3 档粗细、橡皮、撤销、清空、存图 PNG、**穿透**
（开启后点击可穿过涂层去操作页面）。笔迹按题保存。

## 技术说明

纯静态站点，无后端、无构建步骤：

```
index.html
css/style.css    主题：外围粉色渐变 + 题目区纯白
css/ink.css      透明模块
js/store.js      本地记录（答题 / 错题 / 收藏 / 进度）
js/app.js        刷题主逻辑
js/ink.js        透明模块 + 手写引擎
data/index.js    46 套卷索引
data/papers/*.js 每套题的完整数据（按需加载，平均 222KB）
```

数据通过动态注入 `<script>` 加载而非 `fetch`，所以 `file://` 双击也能打开。
